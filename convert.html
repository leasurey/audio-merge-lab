格式转换

浏览器解不了的音频格式（AMR、SILK、WMA、APE…），先转成 MP3 / WAV 再导入本应用。

← 返回应用 使用指南 兼容性自检

先对照：你的是哪种文件？

症状 / 格式说明怎么办
AMR（.amr / .3ga） 手机通话录音最常见格式，浏览器一律不支持 转 MP3（见下方任一方式）
SILK（.silk / 微信语音） 微信语音的私有编码，需专用工具导出 用 silk-v3-decoder 转 MP3
WMA / APE / CAF 旧版 Windows / 无损 / 苹果容器，浏览器不支持 转 MP3 或 WAV
M4A / AAC（提示解码失败） 桌面 Chrome/Edge 不解 AAC；手机一般可以 换手机浏览器，或转 MP3
MP3 / WAV（仍提示失败） 本应用已内置兜底解码器，正常文件都能解 先确认不是 0 字节/云盘未下载；再考虑文件损坏

不确定格式？打开「兼容性自检 → 文件诊断」，选一下文件就能看到真实格式（魔数嗅探）。

方式一：电脑本地软件推荐

格式工厂（国内老牌免费工具，Windows）：拖入文件 → 选「音频 → MP3」→ 开始。官网： pcfreetime.com

Audacity（免费开源，Windows / macOS / Linux）：打开文件 → 文件 → 导出 → MP3。 官网：audacityteam.org

优点：文件不离开你的电脑，适合通话录音、会议记录等私密内容。

方式二：命令行 FFmpeg技术向 · 批量

Windows 安装：PowerShell 执行 winget install ffmpeg；macOS：brew install ffmpeg。 

ffmpeg -i "录音.amr" -b:a 128k "录音.mp3"
ffmpeg -i "音频.wma" -b:a 192k "音频.mp3"
ffmpeg -i "视频.mp4" -vn -b:a 192k "音频.mp3"

第三条用于「从视频里提取音轨」。SILK（微信语音）FFmpeg 原生不支持，需专用工具，见下文。

方式三：在线转换需上传 · 注意隐私

AConvert 中文站（支持 AMR / M4A / WMA 等）： aconvert.com/cn/audio/

Convertio 中文版： convertio.co/zh/audio-converter/

以上为第三方网站，仅为便利提供链接：文件需要上传到对方服务器，我们无法保证其可用性、安全性与隐私政策。 通话录音、会议记录等敏感内容，请优先使用「方式一」的本地软件。
另外：这些站点在中国大陆的实际可达性未经我们验证，打不开属正常情况，请改用本地工具。

微信语音（SILK）专项

微信语音为 SILK 编码，需要专门工具转换。开源方案 silk-v3-decoder： github.com/kn007/silk-v3-decoder （提供 Windows 可执行版本，把 .silk 拖到脚本上即可输出 MP3）。

注意：微信语音文件本身在手机的私有目录里，需先用微信「收藏 / 转存」或文件管理器导出，才有可能转换。
